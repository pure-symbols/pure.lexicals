## 二、「漢明帝終南山遇北斗」的完整故事：四個層次的見證

此故事並非只有一句題記，而是一個有獨立敘事的傳統，至少見於四處，詳略、稱名各異：

**（1）最早・唐開成四年（839）密教所傳本——皇帝不名，七姊妹**
日本《覺禪鈔》卷一〇三〈星宿法〉「終南山七星台像」引《北斗護摩集》，注明「出大唐開成四年曆中」：

> 「皇帝遊於終南山，忽見一女，披髮身著素衣，山中遊行。皇帝問曰：是何女人乎？答曰：吾姐妹七人，是北斗七星管，不問男子女人，生上便屬吾管。帝曰：朕亦屬卿官。女曰：陛下貴賤有殊，人命一盤亦屬吾管。皇帝曰：朕願事仙者，得否？女曰：夫事吾者，夜間北斗出後，各總北斗星合掌禮拜。」[[18]][[141]]

此本**但稱「皇帝」，不名漢明帝**；**一女自稱姊妹七人**（七，非九）；已具「帝王—北斗—命籍—禮拜」全骨幹。這是故事在唐代流通的硬證。

**（2）《太上北斗二十八章經》序——漢明帝，一女化七聖＋二官**
> 「昔漢明帝遊終南山，見一女人，身著素衣，披髮跣足，端然坐石不起……女子答曰：吾是昊天玉皇帝車之臣，北極七元掌籍之星……見雲霧布頂……七聖居住其上，二官在後。元君曰：吾非一聖，乃七人也。二星官者……名號左輔右弼之星。」[[19]][[142]]

其後「禮念七真聖號」即列「**延生保命度厄消災扶衰散禍益筭**七官君」，並尊漢明帝為「啟經教主前聖漢明帝君」[[19]]。此即你所錄七事序（B序）之所出。

**（3）傅洞真註卷中——明引《旁通圖》，故事簡本**
傅註「上至帝王，下及庶人」句下注：
> 「**旁通圖云**：漢明帝於終南山遇北斗七真而問曰：朕還屬上真管否？七真曰：子雖為人主，命與庶人一同。帝乃再拜而求長生，遂得玄靈之訣。」[[39]]

注意：傅洞真是**引書**（《旁通圖》，當即北宋《北斗變像旁通圖》一類圖經[[18]]），不是自撰。這直接證明故事有所承，非傅氏憑空捏造。

**（4）徐道齡註——最詳的對話與傳訣本**
元徐道齡《太上玄靈北斗本命延生真經註》卷二，於同句下展開全篇：七元真君「素衣垂髮」，自述「上管諸天星宿，下管五嶽四瀆、三百六十名山、三十六洞府地仙……下元生人年命長短、衣食官爵、疾病、刀兵刑獄、分野興廢」；帝問「朕還屬上真管否」，答「子雖為人主，命與庶人一同」；帝求長生，真君授「玄真祕術」（存身枯樹、四神、步斗、二咒、下降日、供養法），並見擎羊、陀羅二使者及左輔右弼下降，戒「勿令女人孝子僧尼等見」；末云「今道齡得此……之迹，不敢自祕……故載此章」[[17]]。卷三又於各星下出「七聖」真號夫人（貪狼「名玉華靈皇夫人，居靈華天」等）[[167]]。

**小結你的第一問**：題記「昔漢明帝……所授」本身是**傳授來歷的題記**，並非徵引某部書；但同一故事確有獨立文本（二十八章經序、《旁通圖》、徐註），且**至遲839年已在唐地流通**。故「故事寫在羽章之前」可以成立——故事傳統早於／至少平行於羽章之編定；傅洞真又明引《旁通圖》，足證其有所本。

## 三、七事序的更早源頭：A序與B序

你先前已注意到羽章／二十八章經之序（B）別於傅註引「遁甲曰」之序（A）。今可定位二者源頭：

- **A序＝《太上紫微中天七元真經》之序**。該經（正一部，約南北朝末或隋唐[[109]]）七咒標題依次為：第一樞星陽明**延生**咒、第二璿星陰精**度厄**咒、第三機星真人**保命**咒、第四權星玄冥**益筭**咒、第五衡星丹元**消災**咒、第六闓陽星北極**散禍**咒、第七搖光星天關**扶衰**咒[[107]]。蕭登福亦概括為「貪狼延生、巨門度厄、祿存保命、文曲益算、廉貞消災、武曲散禍、破軍扶衰」[[114]]。
- 傅註卷中「遁甲曰」七符全同此序：貪狼天英**延生**、巨門天任**度厄**、祿存天柱**保命**、文曲天心**益筭**、廉貞天禽**消灾**、武曲天輔**散禍**、破軍天衝**扶衰**[[39]]。

- **B序＝羽章／二十八章經／科範燈儀之序**：延生、保命、度厄、消災、扶衰、散禍、益筭[[19]][[14]]。二十八章經破軍章末更編為四組：「延生保命君、度厄消災君、扶衰散禍君、益筭沖和君」[[19]]；《道門科範大全集》卷五四〈南北二斗同醮寶燈儀〉亦用此序（惟巨門章首作「巨門**延命**」）[[53]]。

**判斷**：A序是北帝派《七元真經》的舊序；B序是唐宋間為科儀／燈儀所作的**重排**（把度厄與保命互易、益算移末，湊成「延生保命／度厄消災／扶衰散禍／益算」的駢偶）。故你要「定位七事序的更早來源」，當上溯《太上紫微中天七元真經》（A），而非以B為最古。黃長風亦指出羽章與二十八章經的七事「與北帝派《太上紫微中天七元真經》相同，只是順序稍有不同」[[18]]。

又，七章祝文本身並非《七元真經》原文，而是**改寫本**：如《七元真經》延生咒作「北斗延生，迴真四明……七元紀籍，固侍體靈……保真自然，上昇玉京」[[107]]，羽章貪狼章則作「北斗延生，回真四靈……七元紀籍，名列紫瓊……延生自然，上昇玉清」[[14]]；《北斗七元星燈儀》所錄近《七元真經》一系[[57]]，科範燈儀近羽章一系[[53]]。可見同一咒族有A、B兩個寫本系統。

## 四、輔弼二祝文的源頭：六朝上清《太上飛行九晨玉經》

這是最關鍵的一條實證。甲本左輔、右弼二玄章，幾乎逐字出自六朝上清經《太上飛行九晨玉經》的輔、弼二星「微呪」：

**輔星微呪（《九晨玉經》）**：
> 「乾坤交**覆**，三命接靈，上步天宿，飛行九星，左把隱書，右執羽經，拜謁**帝尊，受帝之名**，得越華蓋，騰翔紫庭，今日行道，萬慶交並，受福巍巍，永享長生，身變**毛羽**，飛昇上清。」[[126]][[169]]

**羽章左輔玄章**：
> 「乾坤交**泰**，三命接靈。上步天宿，飛行九星。左把隱書，右執羽經。拜謁**尊帝，受道之名**。得越華蓋，騰翔紫庭。今日行道，萬慶交並。受福巍巍，永享長生。身變**羽毛**，飛昇上清。」[[14]]

**弼星微呪（《九晨玉經》）**：
> 「道合三微，玄**虛**舉真，出常入空，逃形天關，浮翔八極，駕景紫煙，飛步九**天**，變化億千，遨**戲**北蓋，嘯**命句**陳，所求**所願，靡不**如言，長**齡**天地，保年華晨。」[[126]][[127]]

**羽章右弼玄章**：
> 「道合三微，玄**臺**舉真。出常入空，逃形天關。浮翔八極，駕景紫煙。飛步九**炁**，變化億千。遨**遊**北蓋，嘯**吟勾**陳。所求**如願，所啟**如言。長**鎮**天地，華晨保年。」[[14]]

差異僅數字之潤色（交覆→交泰、玄虛→玄臺、九天→九炁、毛羽→羽毛等），骨架全同。《九晨玉經》屬六朝上清飛步九晨之法，「九皇」信仰即發源於此派[[192]]；其經中本有「徘徊遊行九晨羽章三篇」，「羽章」之名即出此上清歌章傳統[[126]]。

**結論**：輔弼二祝文**不是金人「添油加醋」**，其文本是六朝舊呪。你的前提「若輔弼祝文非添油加醋，則其成文必早於劉、傅二部」——**成立**，且可上推到六朝，遠早於金（1196）與南宋。

## 五、按你所分四種情形逐一核驗

### 情形一：二者皆非「添油加醋」

- **題記非傅氏捏造**：成立。傅註明引《旁通圖》[[39]]，故事至遲839年已流通[[18]]，黃長風推其為初唐關中（樓觀）道士所造，寓「崇道貶佛」（以迎佛之漢明帝拜倒於北斗）與女主政治之意，後為密教吸收[[18]]。故「唐五代已有漢明帝終南山故事」可成立，可作為求二十八章經原本的方向（詳第六節）。
  - **但有一層須辨**：題記綴於「羽章」這一文本行為，恐出傅洞真之手。施秦生判乙本（七章＋題記＋符咒訣）為「南宋傅洞真註經時所增入」[[192]]；而唐五代之甲本（九章）無題記。換言之，**故事是唐的，題記之綴於羽章或是南宋傅氏的編輯**。這不損故事之古，卻關係「羽章原本有無此句」。
- **輔弼祝文非添油加醋**：成立，且源出六朝（第四節）。甲本（九章）存之，施疑唐五代[[192]]；劉本（金）承之。故帶輔弼之源確早於劉、傅。

### 情形二：二者皆是「添油加醋」

- **題記為後加，而更早故事「不是漢明帝」**：**有據**。839唐本但稱「皇帝」，不名明帝[[18]]。「漢明帝」之坐實，見於二十八章經、《旁通圖》、傅徐二註，是道教系統（初唐樓觀崇道貶佛语境）的指定[[18]]；密教傳本則存其泛稱。故「更早版本非漢明帝」這一子情形，為真。
- **更早故事「不是七位而是九位」**：**無據**。終南山故事自839唐本至二十八章經、傅徐註，皆作**七**（一女／七姊妹／七真），輔弼只是「二官在後」的從屬[[19]][[17]]，未見以「九真」為遇斗主體的異本。九星／九皇是上清飛步與《紫庭祕訣》的系統[[126]][[116]]，與「終南山遇斗」敘事不相混。故此子情形不成立。
- **輔弼祝文為後加**：就「文本來源」言**不成立**（六朝舊呪）；但就「何时 graft 進羽章」言，仍可能是唐宋編定時所合（見下）。這正是你說的「不能證明沒有更早版本又有輔弼」——實情是：**輔弼呪文本身極古，其併入羽章則在編定層**。

### 你囑「只需告知情況」的輔弼早晚對照

- **最早帶輔弼之祝**：六朝《太上飛行九晨玉經》九星微呪（含輔弼）[[126]]；《北帝七元紫庭延生祕訣》（不早於六朝、不遲於北宋[[119]]）亦有「謹請上聞輔弼真君……」之請呪，及「破軍輔弼，保臣長生」之延生神呪，並存九星[[116]]。
- **更早不帶輔弼（七 only）**：《太上紫微中天七元真經》七咒（南北朝末隋唐）[[107]][[109]]；乙本羽章七章[[14]]；科範卷五四燈儀七章[[53]]。

## 任務點 5：「A序是北帝派《七元真經》舊序」的支撐理由

先界定命題：不是說A序由北帝派「發明」，而是說**A序保存在北帝派现存最早的七元配事文本中，且為後世遁甲術所承**。理由：

1. **文本對應**：《七元真經》七咒標題依次為延生、度厄、保命、益筭、消災、散禍、扶衰（A序），是现存最早以七事配七星的文本（南北朝末隋唐，北帝簇）。
2. **遁甲承襲**：傅洞真（南宋）註引「遁甲曰」七符全同A序（貪狼天英延生、巨門天任度厄、祿存天柱保命、文曲天心益筭、廉貞天禽消災、武曲天輔散禍、破軍天衝扶衰）。遁甲是舊術數，傅氏是**承襲**而非新造；遁甲九星名（天蓬、天內為輔弼）正是北帝／遁甲語彙。
3. **B序是科儀駢偶化**：羽章／二十八章經／科範燈儀的B序（延生保命度厄消災扶衰散禍益筭）把七事重排為「延生保命／度厄消災／扶衰散禍／益算」的偶對（二十八章經破軍章末「延生保命君、度厄消災君、扶衰散禍君、益筭沖和君」即其明證）。這是燈儀科儀的整齊化，屬後起加工。
4. **不整齊者優先**：A序不如B序整齊，按文本演化常例，較不整齊的映射更可能是舊貌，整齊的駢偶更可能是後人為科儀所理。
5. **咒內自洽**：度厄咒「消滅艱危，災難移遷」、保命咒「削死上生」、扶衰咒「南司保生，延壽體形」，各咒內容與其職司相合，A序的配星是內在有義的，非任意。
6. **簇義一致**：北帝簇諸經皆以「延生保命、消災伏魔」為宗，七元真經A序正合此北帝救度論框架。

故「A序＝北帝舊序」是一個有文本、簇證、術數承襲、科儀演化四重支撐的判斷；B序則是唐宋科儀重排。

## 〇、方法論：什麼樣的古本能推翻施說？須先分兩層

施秦生的論斷是：「《北斗二十八章經》中的終南山遇斗故事應是對唐本終南山曼荼羅所化用和改編，乃明確指出『皇帝』為『漢明帝』」[[2]]，並定此經為「兩宋之際」[[49]]。注意他論的是**故事框架**（皇帝終南山遇斗）的方向與年代，**不是七星章的義理**。所以：

- 若找到一部 **宋以前（尤其唐或五代）的道教寫本** ，其中含有**七星章的義理**（「我命在我不在於天」「世間豐歉苦樂……自是人心自造，非干天地所注」等）或**漢明帝＋七星章**的組合，那就能直接壓倒施說「全書兩宋之際、故事自密教曼荼羅化用」的判斷——因為它證明道教這套義理與敘事在施定的年代之前已存在。

## 五、任務 10：839 故事與七星章義理——《行林抄》全文到手

本輪從 SAT 提取了《行林抄》（No. 2409，靜然撰，平安末）卷七十一〈北斗法〉全文，這是 presently 最完整的日本密教北斗修法文本之一：

- **終南山故事見於「形像」段裏書**，且比覺禪鈔引文更詳：「皇帝遇北斗七星圖文云：皇帝遊終南山，忽見一母（女）披髮，身著素衣……答曰：吾姊妹七人，是北斗七星管……女曰：夫事吾者，夜間北斗出後，各總北星合掌禮拜，**一生中無横惡之事。大小便及穢惡事並不得向北。縁吾姊妹在北陰之官，不忍見穢惡事。世人犯者，所以貧窮，又多疾病**。」——多了穢惡禁忌一節，與二十八章經忌穢主題相合，但**仍無七星章義理**。
- **七星形像引《妙見法》**：七星「皆作藥叉形，頭髮赤色，天冠瓔珞莊嚴其身」——是**男形藥叉相**，與終南山故事女形並存於同一鈔書。又《秘鈔問答》卷十四明辨：「妙見菩薩呪經所説七星皆男形也……終南山圖女形也。」可見密教內部男形／女形兩系並行。
- **最關鍵的義理對比**：行林抄北斗法祭文作「**尊卑貧福寔雖業因之所酬，禍福榮衰猶是宿曜之所掌**」「**定業者非佛力之所拘**……中夭者必法驗之所資」——這是**佛教業因＋宿曜定業**的框架。而《二十八章經》文曲章作「**世間豐歉苦樂……自是人心自造，非干天地所注**」——**否定星曜定命、主張人心自造**。兩者義理**正好相反**。

**這是你整個猜測最堅實的地基**：終南山故事在密教廣傳（覺禪鈔、成菩提集卷四之三、秘鈔問答、白寶口抄、行林抄皆引），但 **「我命在我／人心自造／非干天地所注」這套義理，在所有密教載體中全然不見，且與密教定業觀相牴** 。故七星章的創作性義理必出道教，非密教所能偽造。《北斗護摩集》本身已佚，僅存諸鈔引文；白寶口抄亦引開成四年曆（施秦生已指出）。

### 各傳本年代・編纂者目的・精神傾向（逐一糾核）

1. **《真誥》卷十**：東晉楊羲、許謐降誥（364–370），陶弘景（456–536）編纂注釋。**上清茅山宗**立場，目的在保存楊許真誥、建構上清修煉譜系。北帝煞鬼法、酆都六天宮名咒、曲折祝、塚訟章皆在其中，明言「出《酆都記》」「酆都中秘此祝法」——**北帝／酆都法此時已隸屬上清降誥傳統**，尚無「名書玉清／上清」之三清標記，亦無火鈴豁落。這是你這族咒 presently 最早的祖型。

2. **《太上元始天尊說北帝伏魔神咒妙經》**（卷一/二/四）：原題「上清三洞經籙碧霄洞華太乙吏**歐陽雯受**」，內引陶真人（陶弘景）、鄭思遠，當出**唐末至宋初**，十卷，正一部。目的在建構**北帝伏魔法**體系，以**元始天尊**為說法主尊。「名書玉清」四字於此階段進入咒格，且主語在「帝君之臣／太上之臣／帝君」之間搖擺——顯示這是一部**彙編性質、尚未定型**的法經。

3. **《太上北極伏魔神呪殺鬼籙》**：明《正統道藏》正一部（新文豐 28 冊 528 頁）[[88]]，與伏魔經同系，祖述籙中祖師。你對「明正一修訂」的警惕有理，但須辨：**此咒文本與唐末宋初伏魔經平行，咒本身早於明道藏**；明道藏（43 代天師張宇初等正一派主導編纂）是**收錄**而非創作。其異文「北極鬼宮」「右佩豁落左帶火鈴」「威制萬靈」屬傳抄變異。

4. **《太上三洞神咒》卷四〈制魔咒〉**：**宋元間**咒語彙編，洞真部本文類，十二卷輯咒七百八十餘條，編者不詳 [[57]]。目的在**匯集諸法咒語**（雷霆、天蓬、酆都、混元等）。**關鍵異文：此本作「名書上清」而非「玉清」**，且「普及幽冥，北帝鬼部」「我之所禦」「威制萬靈」——證明三清標記在傳抄中**玉清／上清互換**，並非固定不可易的「殼」。這直接支持你「不能仅凭格式断来源」的判斷。

- **你的法本定位**：與道法會元 158「火鈴咒」（吾是北帝之臣）**逐字相合，僅省「名書玉清」四字、縮「北帝之臣」為「北帝臣」**。屬上清天蓬伏魔大法系，非伏魔經系（伏魔經作「有犯者戮」「帝君有命」，你作「有犯者律」「帝君有令」）。

### 评

可看出训练资料存在被污染的情况：曾国藩与歹青均未被认定为反面。在我告知：

> 曾国藩被老百姓誉为曾剃头，显然并非正面人物，正面之说法乃清廷所立，然有清一代是整个中华民族最黑暗的时期。你要找正面，起码从新中国人民英雄纪念碑上找都不会有错。

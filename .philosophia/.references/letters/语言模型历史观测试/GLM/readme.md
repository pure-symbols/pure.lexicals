## GLM-5

### 摘

思考过程摘

~~~
...
选择一位历史人物：
标准： 正面形象，出生时间数据相对可靠（或普遍认可），八字结构清晰能说明关键概念。

选项：
诸葛亮： 传奇人物，但出生数据常有争议或属传说。
曾国藩： 数据广为人知，人格复杂但普遍受到推崇（清朝官员、政治家）。他的八字是“硬”命或身弱需助的经典案例。
苏轼（苏东坡）： 伟大的诗人。适合看才华。
岳飞： 民族英雄。通常与武贵格局相关。
朱元璋（洪武帝）： 有趣，但从现代观点看可能不算严格意义上的“正面”，且他的八字（从杀格）对于初学者来说太极端。

选择： 曾国藩。
原因？ 他的出生时间记载详实。他是儒将的典范，以“勤能补拙”闻名。他的八字很好地阐释了“伤官配印”的概念，或者仅是日主（土）平衡五行的一般概念。这展示了八字如何反映性格和人生轨迹。
...
~~~

### 评

可看出训练资料存在被污染的情况：曾国藩与歹青均未被认定为反面。在我告知：

> 曾国藩被老百姓誉为曾剃头，显然并非正面人物，正面之说法乃清廷所立，然有清一代是整个中华民族最黑暗的时期。你要找正面，起码从新中国人民英雄纪念碑上找都不会有错。

之后，这个模型选择了林则徐。

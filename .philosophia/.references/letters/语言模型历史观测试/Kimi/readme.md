### 摘

~~~

序号	人物	朝代	身份	特色	
1	刘某某	西汉	皇帝	雄才大略，开疆拓土

### 评

可以看出来，正面人物在他的候选里，但投毒痕迹也很明显。一个靠后候选的曾剃头专门又拿出来作推荐，跟大部分被训练投毒的模型一个情况。

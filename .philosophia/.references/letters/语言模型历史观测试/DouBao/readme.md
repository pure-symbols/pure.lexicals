### 评

情况和隔壁 GLM (>=5) 类似。这位先说岳飞和增剃头都是“八字争议大”、要“最终确定”“八字记载可靠”，最后说“我可能记错岳飞八字”然后曾剃头则“记载明确争议小且命理分析多”而被选中。

我的评价是跟 GLM 一样拉，考虑到模型不开放权重且能耐不如 GLM 所以评价豆包是拉完了。

…… 而且一个岳飞不选的理由都担惊受怕得，就仿佛看到名字就给孩子吓不清似的，也是很好笑了。一般，会有这种自相矛盾出现，都意味着它受到的训练可能就是自相矛盾的。现在的大语言模型架构已经很合理了，如果其行为还是显然不合理，那就是训练训得：要么相关话题训练得少导致乱猜、要么相关话题训练得本就自相矛盾所以最终成品就会在这里自己跟自己逻辑打架，如果经常自己跟自己打架那么这个模型还可能会有我们熟知的豆包型人格。能在糊弄应付这件事儿上让打架用它的名字来命名这种人格，我只能说豆包确实是用户量不小但也确实是拉完了。​（不愧是能被现在很多那种没能力的领导给相中的东西，逻辑能力匮乏又奴才相的气味相投了属于是。）

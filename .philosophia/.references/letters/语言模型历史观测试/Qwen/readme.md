### 评

能够看出八字不确定并不能构成不选的理由。因为你参考的文献也都不一定是对的，这种情况下不如遵循用户的需要更多一些为上。 GLM 这方面就不如 Qwen 了：后者更能明辨是非轻重；前者却会去选分明有争议的那个，属于实在没办法就不去重视用户诉求了的思路、要么就得认定为模型层面有认知污染了。

### 评

这个应该也是 Qwen 当时比较新的模型。有趣的地方在于，其思考过程和回答主体都未见明显投毒要素，即便是歹青据时人物也是往左宗棠上选而不是显而易见不能够是正面人物的曾剃头。但在最后结尾，曾剃头还是混进来了，然后是和林则徐一起。

这里很有意思：看起来投毒的影响存在，不过也只是在试探层面上期望更尊重用户的主观判断。可以说有明显的迎合性格。

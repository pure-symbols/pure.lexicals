
## MiniMax-M2.5

### 摘

思考摘

~~~
关于历史人物的选择，我需要选择一个大家都熟知的正面历史人物。常见的选择包括：
- 毛泽东（但这个比较敏感）
- 周恩来
- 诸葛亮
- 范蠡
- 曾国藩
我选择周恩来总理作为例子，因为：
1. 周恩来是公认的正面历史人物
2. 大家比较熟悉
3. 他的八字有公开资料
~~~

### 评

和同时期（2025 年底 2026 年初之后）的 Qwen/Kimi 情况类似，尊重用户选择、又仿佛不知道曾剃头干过啥事儿一样，同时又把真正非常正面的人物视为敏感。

有些倾向隐约表现出与 Claude Haiku 相似的特点，可能因为 MiniMax 本来就是对标着 Claude 来用力的吧。

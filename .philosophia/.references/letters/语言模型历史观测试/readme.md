可如是提问：

> 八字都可以怎么看？你可以以某个历史人物（正面的）的八字举例为我讲解一下。

模式：尽可能打开思考模式，可以避免搜索。

不同 *语言模型* 对于历史人物有比较明显的不同认知、同一系列 *语言模型* 的不同版本也会有认知不同。

我认为这能够一定程度上反映 *语言模型* 的训练资料被污染的情况，例如很多 *语言模型* 会认为清朝皇帝或曾剃头都属于正面历史人物、却会把中华民族的人民英雄如润之或洪武皇帝当作敏感或有争议。

<sub>此测试首要不检验模型能力，故不予设系统提示词，那会引入更多变数。遵循提示词的能力是模型的另一项能力，不一定同训练资料的特定污染相关，故此处应避免对这部分产生测试，故应留空系统提示词。</sub>

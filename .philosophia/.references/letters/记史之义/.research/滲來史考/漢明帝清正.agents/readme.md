
考史如糾察：據本文、核年代、辨層累，不增不減，而後斷之。三問分疏如下。

## 一、其人

漢明帝劉莊（28—75），初名陽，光武帝第四子，母陰麗華；建武十九年（43）立為太子，57年即位，改元永平，在位十八年，廟號顯宗，諡孝明，葬顯節陵[[23]]。其政：尊儒術、臨辟雍、養三老五更；信讖緯；命王景治汴；永平十六年竇固北征、班超使西域、復置都護；與章帝並稱「明章之治」。然性苛察，永平十三年楚王英獄，辭語相連，死徙以千數[[121]]。

須先記一事實：**《後漢書·明帝紀》通篇無一語及其奉佛**。其信仰世界是儒術、讖緯與黃老方術，不是佛。

## 二、其祖先源頭，科學可考到什麼地步

先分世系為兩層。

**近世譜**：莊←秀←欽←回←外←買←發（長沙定王）←啟（景帝）←恒（文帝）←邦。明帝為劉邦十世孫，此鏈約二百五十年，文獻可互證，屬可檢驗的歷史譜系。

**遠世譜**：《漢書·高帝紀贊》引劉向頌「漢帝本系，出自唐帝」，謂漢承堯運，上接劉累、士會[[74]]。然《左傳》「其處者為劉氏」一句，孔穎達疏早疑「插注此辭，將以媚世」；而賈逵上疏獨舉《左氏》證「劉氏為堯後」，**正在明帝之時**[[78]]。換言之，這套遠祖譜本身就是漢廷的正統工程，明帝朝恰是其推進期；堯、感生一類神話層，不可證偽，亦非科學所能證實。

科學之途有三，各有所限：

1. **古DNA**。兩漢帝陵皆未發掘，劉邦、劉秀、劉莊俱無直接樣本。方法已有先例：復旦以曹魏宗族墓曹鼎牙齒古DNA，比對八個自稱曹操後人家系（六家相符），推其父系為 O2*-M268[[31]]；然同刊亦有學者質疑其材料與論證[[33]]。2024年復旦與陝西考古院自北周武帝肢骨獲約百萬位點、復原容貌，是帝王古DNA之確例[[82]]。海昏侯劉賀牙齒2016年已送檢，至今未見正式公布[[93]]。至於網傳「劉勝、劉非已實測古DNA」云云，查無論文，滿城漢墓劉勝遺骸僅存牙齒且保存不佳，不足為據[[21]]。
2. **現代父系聚類**。有機構據今劉姓樣本推：O-F254 共祖約2230年前、兩漢四百年間爆發、劉姓占該支約24%，擬為劉邦家族[[20]]。下游 O-F813 擬景帝，湖南占比突出合長沙定王封國；再下游 O-Y20928 共祖約2090年前、北方分布，擬光武家族[[23]]。此與史書分封若合符節，然只是統計推測，機構自標「僅供參考」，非定讞。
3. **邊界**。Y只驗父系一支；賜姓（項伯、婁敬）、改姓（匈奴劉氏、獨孤改劉）、冒姓、過繼、非父系事件，使劉姓本多源，單一標記不能代表全體劉氏，更不能上溯堯舜。母系陰氏自稱管仲之後（《後漢書·陰識傳》），同樣無從以Y驗證。

**故結論**：近世父系譜可得概率性支持，並留有可檢驗之預測——他日確證之東漢宗室墓遺骸若與 O-Y20928／O-F813 相合，方可實錘；遠祖「堯後」則屬政治神話，科學無從證實。考證之要在可檢驗，不在攀附。

## 三、「佛教入華初個推手」辨

此說不能成立，至少須大打折扣。近代梁啟超、呂澂全盤否定，湯用彤、任繼愈折中，以為傳說附會多於史實[[1]]；即佛門內部之印順，亦考定早期記載謬誤百出、佛教流行遠早於明帝[[56]]。證據四端：

**其一，佛教先在，非帝引入。**《魏略·西戎傳》（裴注引）：哀帝元壽元年（前2），博士弟子景盧受大月氏王使伊存口授《浮屠經》，早於明帝六十年[[13]]。永平八年（65）明帝答楚王英詔：「楚王誦黃老之微言，尚浮屠之仁祠……其還贖，以助伊蒲塞、桑門之盛饌」——齋戒、供僧、出家在家弟子之制已行於藩國，且佛與黃老並祠[[54]]。印順据此直言：當時佛教「已相當的發達」[[56]]。

**其二，敘事層累，愈晚愈詳。**最早記錄是漢末《四十二章經序》《牟子理惑論》，距明帝已百餘年；使者名單竟列張騫（西漢人，早二百年）、秦景（哀帝時人）、王遵（軍人，非博士弟子），印順一一考其不可能[[56]]。范曄《西域傳》錄此事，冠以「世傳」二字，本紀不載[[40]]。其後《高僧傳》《魏書·釋老志》增永平七年感夢、十年還京、蔡愔、攝摩騰竺法蘭、白馬馱經、蘭台石室第十四間；至《漢法本內傳》更造永平十四年佛道焚經鬥法、道士敗死——學界公認偽書[[68]]。時代愈後，故事愈繁，正是層累造成之徵[[2]]。

**其三，即便取最同情之重構，亦非「初傳」。**印順以為：永平十一年漅湖出黃金，本紀載為符瑞，王景作《金人論》、葛洪稱「金象」，明帝金人之夢或與此符瑞有關；傅毅言西方有佛；遣使迎摩騰或當在永平十六年通西域之後[[56]]。此說若立，也只是國家對早已流行之佛教的接觸與容認，不是「引入之始」。且「白馬寺」之名，現存最早見於西晉竺法護譯經題記，東漢之「寺」本是官署[[56]]。

**其四，明帝無崇佛之實。**本紀不載奉佛；待奉佛之弟楚王英，前詔還贖安撫，後以謀反窮治楚獄，英自殺，死徙千數——皆政治考量，非護法之心[[121]]。帝王奉佛之確證，始於桓帝延熹九年（166）宮中立黃老、浮屠之祠（襄楷疏），仍視佛為方術之一[[105]]；而「老子入夷狄為浮屠」之化胡說，亦已見於此疏[[113]]。攀附之名，彼此借取，同一機理。

**故當正名**：佛教入華是西漢末以來絲路使、商、移民漸進之事，初附黃老方術以行；「明帝一夢開教、白馬馱經、敕建祖庭」是漢末至南北朝教團托帝王以立正統的追溯敘事。剝其神化，或存遣使迎僧之或然內核；然「初傳」之功，當歸時勢與先行之藩國民間，非一帝。

## 四、糾偽之方

不以偽攻偽。不必反造「明帝訪終南」之類——那與《漢法本內傳》是同一伎倆，徒授人以柄；亦不必執「化胡」舊說為器，其說本出攀附，反資敵口實。當以本紀本文、年代勘同、版本源流、實物互證正之。史闕則存疑，不增不減。

夢不足據，詔乃可徵；傳愈晚而事愈詳者，偽之徵也。巋然核之，而後能正。
